# SketchBillet tutorials

Step-by-step projects. Each one builds a real part you can 3D print, and teaches
one or two new ideas on the way. Do them in order.

| # | Tutorial | You'll learn | Time |
| --- | --- | --- | --- |
| 1 | [Keychain tag](01-keychain-tag.md) | Steps, boxes, cylinders, cutting a hole, exporting for 3D printing | 10 minutes |
| 2 | [Desk organizer](02-desk-organizer.md) | Joining bodies, cutting several holes, renaming steps, positions in x, y and z | 20 minutes |
| 3 | [Sketched name tag](03-name-tag.md) | Sketches, constraints and dimensions, extrude, changing a part with one number | 20 minutes |
| 4 | [Spinning top](04-spinning-top.md) | Sketching on a standing plane, revolve, rounding corners in a sketch | 15 minutes |
| 5 | [Mounting plate](05-mounting-plate.md) | Holes for screws: screw sizes, counterbores, tapped holes, placing holes two ways | 15 minutes |
| 6 | [Fan cover](06-fan-cover.md) | Circular and linear patterns, a grid of holes | 15 minutes |
| 7 | [U bracket](07-u-bracket.md) | Joining boxes, mirroring half a part | 10 minutes |

For now the tutorials use `sketchbillet_cli`, SketchBillet's command-line tool. When the desktop
app arrives, each tutorial gets a version with buttons and screenshots; the
steps stay the same, because the buttons run the same commands.

Every command in these tutorials is run by SketchBillet's tests, so the output you see is
exactly what SketchBillet prints.

**Before you start:** build SketchBillet (see the main README) and find `sketchbillet_cli` (see
[Where to find it](../cli/README.md#where-to-find-it)). Make an empty folder for
your work and run the commands there.

Want to make your own plugin instead? See the
[plugin developer guide](../plugin-guide/hello-plugin.md).
